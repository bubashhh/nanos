# Romantic Troll Quiz ❤️

A small Georgian-language romantic quiz built with React, TypeScript, and Vite. The troll answer has a different evasive personality on every question; the positive answer is identified by its explicit `type`, so its position never affects progression.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Setup

```sh
npm install
npm run dev
```

## Checks

```sh
npm run typecheck
npm run lint
npm run build
```

The production output is written to `dist/`. Existing standalone HTML, audio, and photo files in the workspace are kept intact; the Vite app starts from `index.html`.
